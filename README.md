Student Record Management System

Project Overview

The Student Record Management System is a menu-driven application developed using C programming. It helps manage student records through file handling.

Features

- Add new student records
- Delete student records
- Modify student details
- Display student records
- Sort student records
- Reverse student records

Technologies Used

- Programming Language: C
- Concepts: Structures, Pointers, File Handling
- Build Tool: Makefile

Project Files

- "stud_main.c" – Main program
- "stud_add.c" – Add student records
- "stud_del.c" – Delete student records
- "stud_modify.c" – Modify student records
- "stud_show.c" – Display student records
- "stud_sort.c" – Sort student records
- "stud_rev.c" – Reverse student records
- "student.h" – Header file
- "Student.dat" – Student data file
- "Makefile" – Compilation instructions

Compilation and Execution

make
./student
